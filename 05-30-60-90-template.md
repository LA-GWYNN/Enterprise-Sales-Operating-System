# 30/60/90-Day Plan Template for a New Sales Role or Territory

**Purpose:** A plan that shows reasoning, not just a task list. It states the assumptions behind it, the targets it builds toward, how progress will be measured, and what would change the plan.

**Important:** Everything below is blank or illustrative. Replace placeholders with your own figures. Mark every item as **Fact**, **Assumption**, **Hypothesis**, or **Estimate**. Do not present an estimate as a result.

## 3. Pipeline coverage math

**Formula:**

```
Required pipeline = Target bookings / Win rate
Coverage ratio    = Required pipeline / Target bookings = 1 / Win rate
Opportunities needed = Required pipeline / Average deal size
```

**Illustrative only (invented numbers):** If target bookings were $X and the win rate were 25%, required pipeline would be 4X (a 4:1 coverage ratio). If the average deal were $Y, opportunities needed = 4X / Y.

## 10. What would change this plan

| If I learn... | Then I will... |
|---|---|
| Win rate is materially lower than assumed | Increase pipeline target or tighten qualification |
| One persona converts far better than others | Shift effort and messaging toward it |
| Sales cycles exceed the quarter | Re-weight toward early-stage pipeline and multi-year framing |
| A segment lacks a compelling trigger | Deprioritize and revisit |
